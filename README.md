# MediScan 🩺

## AI-Based Wound & Burn Severity Assessment

MediScan is an AI-based healthcare application designed to provide a preliminary assessment of wounds and burns using an uploaded image and basic information provided by the user.

The system analyzes the injury and provides an indication of its **severity**, along with general guidance on what the user can consider doing next.

> **Disclaimer:** MediScan is an academic project for informational and preliminary assessment purposes only. It is not a replacement for professional medical diagnosis or treatment.

---

## 🎯 Problem Statement

It can be difficult for a person to understand how serious a wound or burn is just by looking at it.

MediScan aims to make the initial assessment easier by allowing users to:

- Upload an image of the wound or burn
- Describe their symptoms
- Get an AI-based assessment
- Understand the possible severity of the condition
- Receive basic guidance based on the result
